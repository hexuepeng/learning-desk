# 学习台 learning-desk

家庭定制学习台：给 8 岁孩子用的多学科壳，**英语先行**（背词 / 默写 / 绘本）。爸爸根据孩子反馈加工具。内容是本机家长词包，不捆绑商业词库或教材。

当前版本 **0.1.7**。iPhone + iPad（平板是孩子主设备）。

## 产品摘要（v0.1.7）

- **iPad 布局**：字号和按钮按平板加大；横屏首页左右分栏、绘本图文并排；排字母可先点空格再点字母，格子随词长缩放，并有清空重排
- **默写三星**：一轮全对 ★★★，错 1–2 个 ★★☆，否则 ★☆☆；连续 3 天满分有本机小庆祝（不是连胜贴纸）
- **今日卡**：背词/默写分条进度；最近错的词优先进入默写半边；做完有短庆祝
- **告诉爸爸**：一键「太难了 / 太简单 / 没意思」，可加一句；书桌收件箱可标已处理
- **首页**：今日英语卡（一半背词 + 一半默写）、英语入口、数学/语文占位、连胜贴纸、「告诉爸爸」
- **英语馆**：背单词、默写台阶、绘本（两本原创短故事 + **我家的书** 本机相册绘本）
- **相册书**：爸爸起书名，从相册选图或现场拍照；每页一张照片 + 英文说明 + 可选中文释义 + 可选家长录音。孩子翻页 / 滑动阅读，点听：有录音听爸爸，否则英语 TTS。照片和录音拷进应用文档目录，只留本机
- **爸爸书桌**（首页连点版本号 5 次，默认密码 `1234`）：进度、词表增删/粘贴（`english,chinese` 或 CSV，追加或清空替换；不捆绑剑桥全表）、**每个词录/重录/删发音**、默写题型开关、留言收件箱、相册书编辑/删书删页/页说明录音
- **默写台阶**：选单词 → 填字母 → 排字母 → 看中文写 → 听写。默认前三档开、自动升降开；后两档默认关
- **发音**：设备自带英语 TTS；若该词（或绘本页）有家长录音，孩子点「听一听」优先播录音。删掉录音后回到 TTS
- **不做**：上架、EAS 正式包、云同步、账号、广告、社交、AI 对话、真数学/语文

## 在 iPhone / iPad 上用 Expo Go 试

1. 安装 [Expo Go](https://expo.dev/go)（iOS App Store）。
2. 电脑安装 Node 22+，在仓库根目录：

```bash
npm install
npx expo start
```

3. 用相机扫终端里的 QR。iPhone 和 iPad 都可以。同一 Wi-Fi，或用 `npx expo start --tunnel`。
4. 孩子主用 **iPad**；爸爸可用 iPhone 点开书桌（首页底部 `v0.1.7` 连点 5 次，密码 `1234`）。

### 试家长录音覆盖 TTS

1. 书桌 → 词表。第一次按「录爸爸的发音」时允许 **麦克风**。系统说明和使用中的提示都是：录音只留在这台设备，不会上传。
2. 对着麦克风读单词，按「停止」（最长约 10 秒会自动停）。该词会显示「已有爸爸的声音」。
3. 孩子打开今日卡或英语馆背单词 / 默写，点「听爸爸的声音」：应听到刚才的录音，而不是设备朗读。
4. 回到词表按「删掉录音」：孩子再听会回到设备英语 TTS。
5. 可选：书桌 → 我家的书 → 某一页，同样可录英文说明。

Web 上麦克风和 TTS 能力有限，请以 Expo Go 真机为准。

### 试一本「我家的书」

1. 英语馆 → 绘本 →「用相册做一本」，或书桌 →「我家的书」→ 起书名后进编辑。
2. 第一次选图时允许 **照片** 权限；第一次拍照时允许 **相机** 权限。系统会说明照片只留在这台设备。
3. 加至少两页：每页一张照片、一句英文说明、可选中文释义、可选爸爸录音。
4. 做成后孩子打开该书：左右滑或点上一页/下一页，点听朗读英文说明（有录音先播录音）。

开发者菜单：设备上三指连点（或摇一摇）。横竖屏都可用：竖屏单列，iPad 横屏首页与绘本分栏。排字母先点要填的空格（高亮），再点字母；格子按词长缩放，点格子可把字母放回。

```bash
npm test          # 默写 / 今日卡 / 词表解析 / 相册书 / 录音覆盖 TTS
npm run typecheck
npx expo start --web   # 浏览器粗看；TTS/相册/相机/麦克风在 Web 上能力有限
```
