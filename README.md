# 学习台 learning-desk

家庭定制学习台：给 8 岁孩子用的多学科壳，**英语先行**（背词 / 默写 / 绘本）。爸爸根据孩子反馈加工具。内容是本机家长词包，不捆绑商业词库或教材。

当前版本 **0.1.0**。iPhone + iPad（平板是孩子主设备）。

## 产品摘要（v0.1）

- **首页**：今日英语卡（一半背词 + 一半默写）、英语入口、数学/语文占位、连胜贴纸、「告诉爸爸」
- **英语馆**：背单词、默写台阶、绘本（两本原创短故事 + 本机相册书）
- **爸爸书桌**（首页连点版本号 5 次，默认密码 `1234`）：进度、词表增删/粘贴、默写题型开关、留言收件箱
- **默写台阶**：选单词 → 填字母 → 排字母 → 看中文写 → 听写。默认前三档开、自动升降开；后两档默认关
- **发音**：设备自带英语 TTS；家长录音覆盖仅预留开关文案
- **不做**：上架、EAS 正式包、云同步、账号、广告、社交、AI 对话、真数学/语文

## 在 iPhone / iPad 上用 Expo Go 试

1. 安装 [Expo Go](https://expo.dev/go)（iOS App Store）。
2. 电脑安装 Node 22+，在仓库根目录：

```bash
npm install
npx expo start
```

3. 用相机扫终端里的 QR。iPhone 和 iPad 都可以。同一 Wi-Fi，或用 `npx expo start --tunnel`。
4. 孩子主用 **iPad**；爸爸可用 iPhone 点开书桌（首页底部 `v0.1.0` 连点 5 次，密码 `1234`）。

开发者菜单：设备上三指连点（或摇一摇）。横屏在 iPad 上可用；排字母是点选格子，触控热区按平板加大。

```bash
npm test          # 默写 / 今日卡 / 词表解析
npm run typecheck
npx expo start --web   # 浏览器粗看；TTS/相册在 Web 上能力有限
```
