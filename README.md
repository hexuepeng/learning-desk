# 学习台 learning-desk

家庭定制学习台：给 8 岁孩子用的多学科壳，**英语先行**（背词 / 默写 / 绘本）。爸爸根据孩子反馈加工具。内容是本机家长词包，不捆绑商业词库或教材。

当前开发版本 **0.1.29**（写入已有 EAS projectId）。产品功能仍是 0.1.27 的两次迭代。iPhone + iPad（平板是孩子主设备）；系统分享、跨设备媒体恢复和横竖屏仍需真机验收。

后续开发见 [版本迭代计划](docs/版本迭代计划.md)，包含 0.1.26—0.1.31 路线及逐版实现、迁移和验收要求。

本次实现与验证见 [0.1.26—0.1.27 验收记录](docs/验收/0.1.26-0.1.27-验收记录.md)。完整备份入口：爸爸书桌 → 备份。

## 产品摘要（v0.1.27）

- **iPad 布局**：字号和按钮按平板加大；横屏首页左右分栏、绘本图文并排；排字母可先点空格再点字母，格子随词长缩放，并有清空重排；选单词在平板上两列选项，答完收起题目区，下一题不用再往下找
- **默写三星**：一轮全对 ★★★，错 1–2 个 ★★☆，否则 ★☆☆；连续 3 天满分有本机小庆祝（不是连胜贴纸）
- **今日卡**：每天抽 10 个词，拆成背词 5 + 默写 5；词不够则有多少用多少。当天卡偏少会按新额度重建。最近错的词优先进入默写半边；做完有短庆祝
- **告诉爸爸**：一键「太难了 / 太简单 / 没意思」，可加一句；书桌收件箱可标已处理
- **首页**：今日英语卡是唯一主按钮（一半背词 + 一半默写）；英语入口、数学/语文占位、连胜贴纸；KET 闯关 / 今日短句 / 错词复习 / 「告诉爸爸」收进轻量「更多练习」或英语馆，不再和主卡抢视线
- **KET 闯关**：和今日英语卡并行，默认不计入今日进度。新装或本机闯关词库为空时，自动种入内置默认包（约 1792 词，按文件顺序）。书桌仍可一键「导入 KET 包」，也可粘贴 `english,chinese` 或 `english,chinese,ipa` 并勾选「用于闯关词库」。孩子三关：听音选词（选项同时显示英文和中文）、听中文选词、跟读（「我读好了」）。新装每天新词默认 5，书桌可调 5/10/20/30；新生成日任务复习优先，新词和复习合计最多 10 个词，三关最多 30 次作答。升级前当天已生成的大任务保留，新上限次日生效。点「下一题」保存本题结果，返回或重启后继续；跟读记录为自评。学会后仍按第 1/2/4/7 天自动复习。英式 `en-GB` TTS / IPA。英文词目对照公开的剑桥 A2 Key 词汇指引整理；中文释义和音标是家里准备的，不是上架商品，不主张剑桥授权。
- **完整备份**：在原生应用导出单个 ZIP，包含所有孩子档案、设置、学习进度、照片，以及单词/短句/书页录音。选择文件后预览、确认替换；媒体先写新文件，状态和媒体读回通过后才清理旧文件。中断恢复有回退记录，损坏存档保留原文并显示恢复入口。旧 JSON 仍支持；Web 提供仅数据 JSON 下载和粘贴恢复。当前容量保护为最多 500 个媒体文件、单文件 8 MiB、总内容 48 MiB；这是保守工程限制，iPad 实际容量和跨设备播放尚待验收。
- **Power Up 1 家庭单元包**：书桌词表列出 Hello! + Unit 1–10（约 186 词）。点一个单元就追加到现有词表（相同英文跳过），并插到闯关顺序前面，方便先练这个主题。不覆盖内置 KET / A2 Key 默认包，也不清已有闯关进度。默认可同时追加该单元短句到今日短句库。词和句来自家庭 EnglishStudy 词表，主题对齐 Power Up 1，不是剑桥官方产品。
- **今日短句**：家庭短句库（本机）。爸爸可粘贴导入（每行一句英文，或 `english,chinese` / `sentence|chinese` / CSV 两列；追加或清空替换；重复英文跳过），也可从 Power Up 1 单元一键带入，或手加一句、改/删/搜索。可选「用当前词表拼几句」本地模板（I/You/We 与少量英式槽位，不是商业句库）。孩子从英语馆或首页进入，一句一屏听读：听一听 / 我会说了 / 下一句；英式 TTS，可选用家长录音。练习不计入今日卡。句中对上词表的词可点看释义。不内置云端 AI 生成。
- **英语馆**：背单词、KET 闯关、默写台阶、今日短句、绘本（两本原创短故事 + **我家的书** 本机相册绘本）
- **孩子档案**：词表和我家的书归在一个孩子档案下，可改名、再加、收入档案柜（为以后多个孩子做准备）
- **本周小结**：书桌里看本周练了几天、默写正确率、最常错的词（本机）
- **错词复习**：首页 / 英语馆入口，5 分钟计时，专练错过的词，不计入今日卡
- **绘本点词**：原创短绘本和我家的书里点英文词，可加进今日词表
- **相册书**：爸爸起书名，从相册选图或现场拍照；每页一张照片 + 英文说明 + 可选中文释义 + 可选家长录音。孩子翻页 / 滑动阅读，点听：有录音听爸爸，否则英语 TTS。照片和录音拷进应用文档目录，只留本机
- **爸爸书桌**（首页连点版本号 5 次，默认密码 `1234`）：进度、词表增删/粘贴（`english,chinese` 或可选第三列英式 IPA：`apple,苹果,/ˈæpl/`，追加或清空替换）、一键「导入 KET 包」（内置约 1792 词，按文件序重排闯关词库）、按单元导入 Power Up 1 家庭包（追加、不覆盖）、勾选「用于闯关词库」、每个词可改音标 / 标闯关、每天闯关新词上限 5/10/20/30 及延期数量、**每个词录/重录/删发音**、短句库增删/粘贴/本地拼句、默写题型开关、留言收件箱、相册书编辑/删书删页/页说明录音、完整备份与恢复
- **英式音标**：词可带可选英式 IPA（存成 `/ˈæpl/`，导入时可省略斜杠）。书桌开关「显示音标」默认开；孩子背词、默写揭晓答案时显示在英文下面。示例词包只给少量核对过的音标，不批量编造、不内置商业词库
- **默写台阶**：选单词 → 填字母 → 排字母 → 看中文写 → 听写。默认前三档开、自动升降开；书桌可一键打开挑战档（看中文写 + 听写），键盘题会提示字母数、听写可反复听
- **发音**：设备优先英式 `en-GB` TTS（语速约 0.68，音高接近自然）。有多种英式系统音时，优先选 Daniel / Kate / Serena / Martha / Arthur 等常见高质量音色，再退回任意 `en-GB` / `en-UK`，最后才用其他英语。听感仍取决于本机是否安装了英式语音包，应用不捆绑云端 TTS。若该词（或绘本页）有家长录音，孩子点「听一听」优先播录音。删掉录音后回到 TTS
- **不做**：公开商店商品、云同步、账号、广告、社交、AI 对话、真数学/语文。家庭 TestFlight 已备 `eas.json`，并已关联 Expo 项目 `@hexuepengs-team/learning-desk`，尚未 build / submit

## 在 iPhone / iPad 上用 Expo Go 试

1. 安装 [Expo Go](https://expo.dev/go)（iOS App Store）。
2. 电脑安装 Node 22+，在仓库根目录：

```bash
npm install
npx expo start
```

3. 用相机扫终端里的 QR。iPhone 和 iPad 都可以。同一 Wi-Fi，或用 `npx expo start --tunnel`。
4. 孩子主用 **iPad**；爸爸可用 iPhone 点开书桌（首页底部 `v0.1.29` 连点 5 次，密码 `1234`）。

### 试家长录音覆盖 TTS

1. 书桌 → 词表。第一次按「录爸爸的发音」时允许 **麦克风**。系统说明和使用中的提示都是：录音只留在这台设备，不会上传。
2. 对着麦克风读单词，按「停止」（最长约 10 秒会自动停）。该词会显示「已有爸爸的声音」。
3. 孩子打开今日卡或英语馆背单词 / 默写，点「听爸爸的声音」：应听到刚才的录音，而不是设备朗读。
4. 回到词表按「删掉录音」：孩子再听会回到设备英语 TTS。
5. 可选：书桌 → 我家的书 → 某一页，同样可录英文说明。

Web 上麦克风和 TTS 能力有限，请以 Expo Go 真机为准。

### 试一本「我家的书」

1. 英语馆 → 绘本 →「用相册做一本」，或书桌 →「我家的书」→ 起书名后进编辑。
2. 第一次选图时允许 **照片** 权限；第一次拍照时允许 **相机** 权限。系统会说明照片只留在这台设备。
3. 加至少两页：每页一张照片、一句英文说明、可选中文释义、可选爸爸录音。
4. 做成后孩子打开该书：左右滑或点上一页/下一页，点听朗读英文说明（有录音先播录音）。

开发者菜单：设备上三指连点（或摇一摇）。横竖屏都可用：竖屏单列，iPad 横屏首页与绘本分栏。排字母先点要填的空格（高亮），再点字母；格子按词长缩放，点格子可把字母放回。

```bash
npm test          # 默写 / 今日卡 / 词表解析（含英式 IPA） / 短句导入与本地模板 / KET 闯关 SRS 与导入 / Power Up 1 单元包合并 / 相册书 / 录音覆盖 TTS
npm run typecheck
npx expo start --web   # 浏览器粗看；TTS/相册/相机/麦克风在 Web 上能力有限
```

## iPad TestFlight（EAS）

配置在仓库根目录 `eas.json`。目标是把 **production** 商店包交到 TestFlight，再装到 iPad（`supportsTablet: true`，bundle id `com.hexuepeng.learningdesk`）。

| profile | 用途 |
| --- | --- |
| `development` | iOS 模拟器包（`distribution: internal`，`ios.simulator: true`）。没有 `expo-dev-client`，不是开发客户端 |
| `preview` | internal / ad hoc，装到 Apple Developer 里已登记的设备 |
| `production` | App Store / TestFlight。`autoIncrement: true`，且 `cli.appVersionSource` 为 `remote`，EAS 远程递增 iOS `buildNumber`。用户可见版本仍是 `app.json` 的 `version` |

`eas-cli` 未写入依赖。脚本会临时用 `npx eas-cli`：

```bash
npm run eas:build:ios            # production，TestFlight 用这个
npm run eas:build:ios:preview    # ad hoc / internal
npm run eas:build:ios:simulator  # 模拟器
```

提交到 TestFlight（同样不要在没有凭据时运行）：

```bash
npx eas-cli submit --platform ios --profile production
```

Expo 项目已关联：`owner` 为 `hexuepengs-team`，`extra.eas.projectId` 为 `11cba1d7-51b3-4a0a-8050-b507357ed707`。不要改这个 id，也不要再 `eas init` 新建项目。还缺的步骤都在仓库外，需要已有 Expo 账号和 Apple Developer / App Store Connect 权限的人来做：

1. `npx eas-cli login` 后直接 build，不必再 init。
2. 首次 `eas build` 时让 EAS 配置 iOS 分发证书和描述文件。凭据留在 EAS，不要提交 `.p8`、`.p12` 或 mobileprovision。
3. `preview` 的 ad hoc 包还要先登记 iPad 的 UDID。TestFlight 走 `production`，不靠 UDID 清单。
4. App Store Connect 里创建 App（bundle id 与上面一致）后，再用 `eas submit` 上传。加密出口合规已在 `app.json` 设为 `ITSAppUsesNonExemptEncryption: false`。
