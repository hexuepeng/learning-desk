# 0.1.27 浏览器流程验收

验收日期：2026-09-30（Asia/Shanghai）。本轮实际浏览器流程通过，未发现阻塞问题。结果仅覆盖下表中的 Web 行为，不代替 iPad、Expo Go 或原生媒体备份验收。

## 环境与操作范围

- 应用版本：0.1.27；测试地址：`http://localhost:8081`。
- 启动命令：在仓库目录运行 `npm run web -- --port 8081 --offline`。开发服务保留运行，执行会话为 `41278`。
- 浏览器：Windows 系统 Microsoft Edge `154.0.4258.37`，headless；自动化运行库使用 Codex 内置 Playwright `1.62.1`，未修改项目依赖。
- 隔离目录：系统临时目录中的 `learning-desk-qa-mslWBU`，由本次验收新建；使用全新本地存储，不涉及用户日常浏览器配置或已有学习记录。
- 视口：默认 `1024 × 768`；完成页另检查 `768 × 1024`。测试后每次均等待 `context.close()` 完成，所有本次 headless 浏览器会话已关闭。
- 所有练习点击都经过真实页面控件。数据注入仅用于一次存储写入失败，以及隔离存档中的损坏 JSON 恢复场景。

最初按 `agent-browser` / `agent-browser-verify` 技能准备专用会话；CLI 临时下载未推进，随后 CUA 的 Edge 标签创建连续报告 `Unable to load browser request-header policy`，会话重置后仍相同。改用已有 Playwright + 独立 Edge 完成实际流程，未以服务启动或 HTTP 成功代替页面验收。
