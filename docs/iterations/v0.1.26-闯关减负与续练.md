# 0.1.26：闯关减负与续练

[返回版本迭代计划](../版本迭代计划.md)

状态：已实现，合入开发版本 0.1.27；自动化及浏览器流程通过，真机及家庭试用待完成。前置版本：0.1.25。结果见[验收记录](../验收/0.1.26-0.1.27-验收记录.md)。

## 1. 用户结果

孩子看到一份数量明确的今日闯关任务，中途返回或重启后能从已提交位置继续。复习词增多时减少新词，做完后有清晰结束提示。

本版保留三关与已有星级规则，不改逐词复习算法。今日卡和 KET 仍独立，首页统一计入规则在 0.1.29 实现。

## 2. 任务量规则

### 2.1 初始参数

| 参数 | 新安装默认值 | 可选值/说明 |
| --- | --- | --- |
| 每日新词上限 `dailyNewCount` | 5 | 5 / 10 / 20 / 30；保留旧选项，含义为最多安排多少新词 |
| 每日闯关总词数 `dailyWordLimit` | 10 | 首版固定 10，家长页展示说明，不增加第二组复杂设置 |
| 每个词的关数 | 3 | 听音选词、听中文选词、跟读；沿用已有顺序 |

总词数指去重的词数。新生成任务最多 10 个词、三关合计最多 30 次必做响应；不是承诺 10 道题或 10 分钟内结束。复听、答案查看不计为额外必做题。

旧存档已设置的 10/20/30 新词上限保留；实际安排仍受总词数 10 约束。书桌明确显示“新词最多 X 个；新词与复习合计最多 10 个”。更丰富的配额设置等家庭观察后再决定。

### 2.2 选词顺序

1. 只使用当前孩子档案内、仍存在于闯关词库的词。
2. 取 `nextDue <= today` 的词，按最早到期优先；同一天到期按已有词库顺序稳定排序。
3. 先放入最多 10 个到期词。
4. 剩余名额放入尚未安排的新词：`min(新词上限, 10 - 已选复习数, 可用新词数)`。
5. 未选中的到期词继续保留原 `nextDue`，不标完成、不推迟其记录日期。
6. 只有实际选入的新词才创建闯关词状态，未选中词不移动已安排数量。

| 到期词 | 新词上限 | 可用新词 | 当天结果 |
| --- | --- | --- | --- |
| 0 | 5 | 100 | 0 复习 + 5 新词 |
| 7 | 5 | 100 | 7 复习 + 3 新词 |
| 12 | 20 | 100 | 10 复习 + 0 新词；2 词保留待复习 |
| 0 | 30 | 100 | 0 复习 + 10 新词 |
| 2 | 5 | 1 | 2 复习 + 1 新词 |
| 0 | 5 | 0 | 无待学任务；不发完成奖励 |

### 2.3 当天稳定与升级

- 任务首次生成后固定 `ids/newIds`，同一天改新词数、导入词包不扩充任务；次日采用新设置。
- 从 0.1.25 升级时保留当天原任务，包括超过 10 词的任务和已过关星级，显示“新的每日上限明天生效”。不能截掉旧任务并把剩余内容标为学完。
- 旧存档 `stars > 0` 仍代表该关已过。未保存过的关内题号无法恢复，不补造历史；升级后的提交开始支持续练。
- 删除词后从当前队列和对应答题映射移除；已提交的其他词保持不变，不补新词扩充任务。全部删除时显示无待学内容，不凭空发星或推进复习。
- 切到新的本地日期时重新安排任务。昨日没完成的复习状态继续参与到期队列，不能把旧页面回调写入新一天。

## 3. 续练与结果提交

### 3.1 提交时机

沿用“选择答案 → 展示解释 → 下一题”的流程，点“下一题”才提交本题结果。仅停留在答案解释页、尚未提交时退出，再进来可以重新做这一题；文案和验收都以“已提交题目”为准。

跟读提交值为 `self-reported`，选择题为 `correct/incorrect`。本版星级可保持旧表现，但不得把自评保存为客观正确率证据。

### 3.2 最小新增状态

在现有 `QuestDay` 添加可缺省的答题结果映射，逻辑键为“关卡序号 + wordId”，值为结果和提交时间。`QuestState` 增加总词数默认值所需的兼容读取；如果固定常量已经足够，不为固定值新增无意义的持久化字段。

- 继续使用 `QuestDay.date` 和所属 `questByProfile` 作为日期、档案边界。
- 当前题根据当前关未提交的词推导，不同时持久化一份易失配的独立题号。
- 映射缺失时补空；旧的已过关状态优先，不要求旧关补齐映射。
- 每个逻辑键最多提交一次；同一按钮快速连点不得重复推进或覆盖首次答案。
- 最后一题提交、该关完成及最终当天结算在一次状态变更中形成，持久化成功后再离开当前题。
- 保存期间禁用重复提交；写入失败保留当前题与反馈，允许重试。写入顺序必须保证较旧快照不会覆盖较新快照。

不新增数据库或通用事件总线。优先在已有 `quest.ts`、`useDesk.tsx` 和存储边界内完成最小改动；如需纯逻辑辅助模块，以实际职责拆分。

## 4. 页面变化

| 页面/状态 | 文案与行为 |
| --- | --- |
| 闯关首页，未开始 | “今天复习 7 个词，认识 3 个新词”；主按钮“开始今天的闯关” |
| 闯关首页，进行中 | 显示当前关和该关完成数；主按钮“继续练习” |
| 练习页 | 显示“第 2 关 · 已完成 4/10”，提交后进入下一未完成题 |
| 最后一题 | 结算后进入完成页，不被 `mode === done` 的提前返回遮住庆祝状态 |
| 闯关完成 | “今天的闯关完成啦”；主按钮“回首页”，不自动开启新一批 |
| 无到期词且无新词 | “今天没有待复习的词”；允许返回英语馆，不等于新完成了一次任务 |
| 爸爸书桌 | 新词上限增加 5；说明复习优先和总词数上限，展示待复习/本日安排/延期数量 |
| 首页今日卡已完成 | 将当前“再练一会儿”改为完成状态或“查看今日成果”；自由练习仍从英语馆进入 |

孩子页不突出积压数量或“欠了多少词”；延期数放在家长页。首页只在今日卡实际完成后改变对应按钮，本版不把完成闯关自动算作今日卡完成。

## 6. 验收用例

| ID | 场景 | 预期 |
| --- | --- | --- |
| AC26-01 | 到期 7、新词充足、每日新词 5 | 正好安排 7 复习 + 3 新词 |
| AC26-02 | 到期 100、新词充足 | 最早到期的 10 词进入任务；其余保持到期状态 |
| AC26-03 | 词库只有 3 词 | 只安排 3 词；三关共 9 次必做响应 |
| AC26-04 | 同一天重复进出并导入新词 | 原计划不扩充，新词不提前标为已安排 |

| AC26-07 | 最后一题快速连点/写入失败 | 只结算一次；失败可重试且不跳到假完成页 |
| AC26-08 | 旧存档当天 50 词且第 1 关一星 | 当天保留 50 词，进入第 2 关；次日新任务遵守上限 |
| AC26-09 | 正在第 2 关时删除一个词 | 队列剔除该词，其他已提交结果保留，能继续完成 |
| AC26-10 | 任务中跨日或切档案 | 旧提交不写入新日/其他档案；恢复目标档案自身任务 |
| AC26-11 | 三关最后一题完成 | 完成反馈可见；重复进入不再结算、不自动加任务 |
| AC26-12 | 无词或词全部删除 | 明确空态；不新增学习记录、星级或连胜 |
