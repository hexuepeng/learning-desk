# 0.1.31：家长周报与下一步建议

[返回版本迭代计划](../版本迭代计划.md)

状态：待实现。前置：0.1.28 事件、0.1.29 日课、0.1.30 主题已可用。

## 1. 用户结果

家长打开周报，可以知道孩子这周完成了什么、哪些词还需要复习、下周可以怎样安排。最多展示三条有具体依据的建议，避免增加查看报表的负担。

全部统计与规则在本机执行。不接入云端分析、AI 评语或孩子排名；不根据少量记录给孩子贴能力标签。

## 2. 指标定义

统计窗口沿用设备本地日期的周一至周日；当前周只包含截至当天实际发生的记录。页面展示孩子名字、日期范围及数据覆盖情况。

| 指标 | 计算口径 | 不计入的情况 |
| --- | --- | --- |
| 练习天数 | 当前档案在本周至少提交一项练习的日期去重 | 仅打开页面、播放声音、其他孩子事件 |
| 日课完成天数 | 当前档案正式完成日计划的日期去重 | 自由练习凑数、空计划、重复发奖 |
| 首次作答正确率 | 同题型中 `correct / (correct + incorrect)`，限定首次提交 | 跟读、自评认识、短句自评、同日重练 |
| 隔天复习结果 | 已标记为到期复习，且上次有效学习在更早日期的客观首次结果 | 新词当天练习、无可验证日期的旧记录 |
| 需要再练的词 | 最近不同日客观错误及当前复习状态，按明确规则排序 | 因删词找不到内容却当成孩子答错 |
| 短句参与 | 完成自评的句数及不同句数 | 不显示为口语准确率 |

听音选词、听中文选词和默写分开显示样本数及正确率，不合并成一个“英语掌握率”。比如“8/10”比只显示“80%”更容易判断依据。

旧记录可支持原来的有限统计，但没有题型、首次标记或归属时，不混入新定义的正确率。没有记录时显示“暂无足够记录”；不能用 0% 表示没有作答。

## 3. 建议规则

首版最多三条，按以下优先级取满足条件且不冲突的建议。阈值是初始产品参数，家庭试用后调整。

| 优先级 | 触发条件 | 展示及动作 |
| --- | --- | --- |
| 1 | 同词在本周至少两个不同日期出现客观错误 | “这几个词值得再练”，列最多 5 词及日期；默写错误连接现有错词复习，闯关错误展示下次复习日，保持日课上限 |
| 2 | 最近至少 3 个有客观题的练习日、首次样本合计至少 15，正确率低于 60%，且存在当前档案的“太难了”反馈 | “可以试着减少新词”；家长查看设置，手动选择后次日生效 |
| 3 | 同词至少两个不同日期的识别复习通过，其中最近一次距此前有效练习至少 7 天 | “这些词隔天还能认出”，列证据；可建议去现有默写页试一试，不自动提升拼写档位 |
| 4 | 当前主题的新词候选已空，且还有可选单元 | “可以选择下一个主题”，提供主题入口；旧词仍继续复习 |

规则 2 的题型口径必须一致；若不同题型表现分化，展示各自样本，不用混合平均值触发。当前新词已经是最低 5 时，不提供无效的“再减一档”，改为提示家长查看复习负担和现有任务安排。

规则 1 只使用完整覆盖区间内的记录；规则 2/3 在必要日期不完整时不触发；规则 4 由当前词库状态判断，不依赖虚构历史。

现有错词复习只消费默写错误，不能假定它已经能练闯关听选错误。首版按来源提供上述动作，不把听选错误伪装成默写错误来复用入口。

建议需要家长实际选择后才改变设置，不能打开周报就自动改变孩子明日计划。家长取消或返回，不发生修改。

## 4. 反馈处理

沿用已有“太难了 / 太简单 / 没意思 / 想说的话”和已读/已处理状态。

- 新反馈记录发送时的 `profileId`，有当前计划时附计划/活动标识，帮助理解反馈针对什么。
- 家长可在标记处理时选一个简短处理结果：“调整了任务”“换了主题”“一起再看看”，并可留一句备注。
- 处理结果用于家长回顾，不自动修改任务或要求孩子回复。
- 旧反馈没有档案归属时保留为历史留言，不用于某个孩子的难度建议。

暂不添加聊天、推送或孩子端通知系统。

## 5. 覆盖范围与边界

- 展示“本周数据从 X 日开始”或“某日记录不完整”；升级前没有收集的活动不显示成零练习。
- 删除词后显示事件中的英文快照，标记已从词表移除；不能通过建议把删除词偷偷恢复。
- 记录中不包含可靠主动学习时长时，不展示平均学习时长或自动给出“练太久”的建议。0.1.26 的人工观察记录仍是外部验收材料。
- 备份恢复后事件 ID 去重，重复恢复不让某周数据翻倍。
- 只显示当前孩子可归属的数据，多档案全局旧历史另作说明。

## 7. 验收

- [ ] 只做跟读/短句的一天显示参与记录，没有伪造口语或默写准确率。
- [ ] 首次错后重做正确，首次正确率不被覆盖；重练仍可查看。
- [ ] 两个孩子在同一天练同一英文，统计和反馈分别归属各自档案。
- [ ] 周日/周一边界和本地日期正确，当前周不包含未来日期。
- [ ] 无数据、部分覆盖、容量截断、旧版升级均有明确提示。
- [ ] 触发建议时显示具体词、日期或样本；低于门槛不输出强结论。
- [ ] 相互冲突或重复建议不会同时出现，最多显示三条。
- [ ] 点击建议后仍由家长完成设置；当天任务保持稳定。
- [ ] 删除词、归档孩子、导入完整备份后统计仍可解释。
- [ ] 测试、类型检查、版本一致性及真实家庭一周使用观察完成。
