# 0.1.30：本周主题与家庭内容串联

[返回版本迭代计划](../版本迭代计划.md)

状态：待实现。前置版本：0.1.29。

## 1. 用户结果

家长选择“本周练 Power Up 1 的某个单元”，日课优先使用对应词和句；学习结束可继续看选定的家庭绘本。减少导入以后还要在多个入口找内容的操作。

首版只提供现有 Power Up 1 单元作为主题来源，可附一册已有家庭绘本。不新增教材抓取、自动拍照识词、云端生成句子或复杂内容编辑器。

## 2. 内容关联

现有单元导入会跳过重复英文；短句已有主题标签，但词条缺少完整的单元归属。因此主题不能靠“最近导入了哪些新词”判断。

新增按档案的内容分组关联，表示一个单元含哪些现有词和短句。同一个词允许属于多个单元，仍只保留一个词 ID 和一份学习进度。

- 单元导入同时关联新词和当前档案中已存在的同英文词。
- 重复导入不增加重复关联，不覆盖家长修改过的释义、音标或录音。
- 对历史内容按内置单元英文及短句标签做确定性匹配；不能确定的关联留空，不根据中文近似猜测。
- 主题设置按档案保存，包括单元 ID、选定时间、可选书 ID。
- 删除词、句或书时清理失效关联；删除主题设置不删除内容或进度。

这是一份内容关联，不再复制一套“主题词表”与原词表互相同步。

## 3. 选词与短句规则

### 3.1 KET 主线

所有已到期词仍优先，不能为了主题跳过旧复习。新词名额从当前主题尚未学过的词中按单元顺序补充；选定主题的新词用完时只做到期复习，不自动加入其他单元的新词，家长可切换主题。

### 3.2 背词默写主线

保留最近错词优先的原则，之后优先当前主题中未练或较早练过的词。仍遵守原主线的任务上限与少词规则，不因主题内容多而加长日课。

在现有今日卡分配逻辑上增加内容范围与优先级即可，不把 KET 的识别状态直接当成拼写掌握程度。

### 3.3 短句与绘本

- 只有家长已经开启日课短句时才加入 1 句；主题选择不暗中开启新的必做项。
- 优先选同单元、且与当日词有明确关联的短句；其次选同单元较少练过的短句。
- 无主题短句时提示“这个主题还没有短句”，当天不强行添加无关句或阻塞计划。
- 词句关联首版使用明确 ID 或标准化的完整单词匹配；不假定已经具备词形还原能力，例如 `apple` 与 `apples` 需要明确关联才能匹配。
- 家长可选择一本已有相册书作为“今天还可以看”；阅读保持自由选择，不自动计入词汇掌握或日课必做。

主题在下一份日计划生效；首份计划尚未生成时可直接使用。中途切主题不会改掉孩子正在做的内容。

## 4. 页面流程

家长书桌 → 本周主题 → 选择单元 → 查看本机已有关联词/句数量 → 缺内容时确认追加已有家庭包 → 可选家庭绘本 → 保存并显示生效日期。

孩子首页显示简短主题名，如“这周认识食物”。具体内容仍通过统一日课开始。结束页可展示“看看我家的书”，没有附书时不显示空入口。

若整个主题暂时没有可用内容，家长页给出“导入该单元”的明确动作；孩子页显示可理解的空态，不默默退回不相关的新词主题。

## 5. 内容质量

本版涉及的单元名称、示例短句、中文对照和词句关联需要抽查，记录发现的问题；发布中实际改到的句子逐条核对。主题对齐教材不代表拥有官方授权，继续沿用现有家庭内容说明。

不为了展示效果批量编造音标或长故事，优先使用现有内容、家长选择与家庭照片。

## 7. 验收

- [ ] 已存在 `apple` 且家长录过音，再导入相关单元，仍是原词 ID 和原录音，并加入主题关联。
- [ ] 同词属于两个单元，切主题不会产生重复词或清空进度。
- [ ] 旧到期词与主题新词同时存在时，先复习且不突破上限。
- [ ] 主题新词用完不会擅自改学其他主题；家长可明确切换。
- [ ] 短句未开启、缺短句、没有词形匹配、无关联书均有确定行为。
- [ ] 学到一半切主题、删词/删书不会丢已提交结果或留下死链。
- [ ] 不同孩子可有不同主题；备份恢复能保留内容关联和选择。
- [ ] 一个单元完成“家长选择 → 日课词句 → 可选家庭绘本”的真机流程。
