# 0.1.29：统一日课与档案独立进度

[返回版本迭代计划](../版本迭代计划.md)

状态：待实现。前置版本：0.1.28。

## 1. 用户结果与默认选择

首页只有一个主要学习动作：“开始今天的学习”或“继续今天的学习”。家长选择适合当前阶段的主线，孩子完成这份计划即可结束当天必做任务。

主线先提供两种，复用已有练习：

| 主线 | 必做内容 | 可选追加内容 |
| --- | --- | --- |
| 背词与默写 | 当前今日卡的背词半边 + 默写半边，沿用最多 10 词及少词规则 | 1 句短句 |
| KET 闯关 | 0.1.26 的有限词数、三关及续练规则 | 1 句短句 |

新装和旧档案默认选择“背词与默写”，避免升级后突然改变熟悉的入口。短句默认不加入必做，家长可以开启。设置改变次日生效，当天计划不重置。

本版不把两套完整主线叠加为一个必做任务，也不按任意点击次数凑完成度。自由练习仍可通过英语馆访问。

## 2. 当日计划规则

### 2.1 生成与稳定

- 计划归属于一个 `profileId` 和本地日期，记录当日主线及短句选项快照。
- 默认最多一份当日必做计划；不要在首页渲染时同时生成两条主线的必做任务。
- 复用既有当天今日卡/闯关任务，若其已完成则同步对应步骤；不重新生成一份要求孩子重做。
- 短句开启且有可用内容时固定 1 句，按未练/较早练过优先；无内容时不生成占位必做步骤。
- 本版先用现有内容范围，主题过滤在 0.1.30 接入。
- 内容删改后修剪失效引用，不重新抽取额外必做题；若因此所有步骤都失效，显示“今天没有可用练习”，不发完成奖励。
- 绘本点词可加入词表候选，明确提示之后安排；不把新词不断追加到已经开始的必做计划。

### 2.2 完成条件

- 背词“认识/不熟”、默写已提交、闯关各关已完成、短句“我会说了”分别表示该步骤的完成。错误也可以完成练习，自评不变成客观正确。
- 从任何入口完成同一个计划内任务，同步对应进度；匹配必须包含档案、日期、任务、内容和题型。
- 计划外自由练习记录到周报，但不替代计划内其他题型或其他词。
- 完成全部有效必做步骤，且至少实际提交过一项有效计划内练习后，才能标记当日完成。
- 正在进行的计划与客观正确率分开：不能因为错误就永远无法完成，不能因为看了答案就宣称已经掌握。

### 2.3 奖励

计划完成后按“档案 + 日期”只发一次完成奖励。重复进入、切换入口或再次自由练习不能重复发贴纸。

各练习原有星级保留其含义；首页按主线展示对应结果。闯关跟读星不混入默写正确率，跟读自评不显示为发音评分。本版沿用已有连胜规则，不另加断签补签系统。

## 3. 页面流程

1. 家长：书桌 → 学习安排 → 选择主线、是否带 1 句短句 → 显示生效日期。
2. 孩子：首页 → 显示今日安排概览 → 开始/继续。
3. 学习：进入当前未完成步骤，仍使用已有背词、默写、闯关与短句组件。
4. 步骤结束：继续下一步骤，最后进入统一完成页。
5. 完成：首页显示“今天的学习完成啦”，主按钮查看成果；英语馆仍可自由练习。

页面使用“背词 3/5”“默写 0/5”或“闯关第 2/3 关”等可理解进度。不要把一整关与一句话的完成数汇总成看似等量的“正确率”。

暂停/返回不会丢失已提交结果。短句为空、主线为空、只剩短句、全部为空都需要独立空态；没有内容不等于完成学习。

## 4. 档案隔离与迁移

现有代码只按档案组织部分内容和闯关，`daily`、`streak`、`stars` 仍为全局。本版必须让新日课及完成奖励按孩子独立存储。

建议新增一个按档案映射的学习状态，内含主线设置、今日计划、今日卡状态及日课奖励；闯关继续复用 `questByProfile`。确切类型名可由实施决定，不能维护两份会互相漂移的完成状态。

| 旧状态 | 迁移规则 |
| --- | --- |
| 仅一个孩子档案 | 今日卡、连胜、默写星等迁入该档案，保留已有结果 |
| 多档案，今日卡所有词能唯一归属一个档案 | 今日卡迁入该档案，不跟随当前界面恰好选中的孩子 |
| 今日卡混合多个档案或无法归属 | 原卡留作迁移历史；为选中档案生成独立新计划，不按混合卡发奖励 |
| 多档案共享的旧连胜/星级 | 作为旧全局历史保留展示说明，不复制到每个孩子或猜测归属 |
| 新事件 | 直接使用 0.1.28 的 `profileId`，不按查看时的当前孩子重新归类 |

迁移只执行一次；重复打开、再次恢复同一旧备份会得到一致结果。切换/归档孩子后重新解析活跃档案，不能提交旧页面回调到新档案。

升级当天存在有效旧今日卡时，默认主线继续该卡，保留其已提交内容；全局历史迁移不应导致同日重复发奖。完整备份包含映射、历史保留区和迁移标记。

## 6. 验收

- [ ] 背词默写主线：一次入口完成必做，首页即时显示完成。
- [ ] 闯关主线：完成闯关及已配置短句后完成日课，不再额外要求另一张今日卡。
- [ ] 从英语馆完成同一计划题目会同步；练其他词不能抵扣。
- [ ] 中途改主线/短句选项只影响次日；同日重启内容稳定。
- [ ] 旧卡升级后继续，已完成日不重复获得奖励。
- [ ] 两档案分别完成、切换、归档和恢复，内容、计划、连胜均不混用。
- [ ] 混合归属旧卡及无法归属旧奖励保留历史说明，不伪造分配。
- [ ] 短句缺失、删除部分内容、所有内容失效均能结束或返回，不假发完成奖励。
- [ ] 错题仍可完成当天任务，自评不进入客观正确率。
- [ ] 真机横竖屏、重启、跨日及完整备份恢复通过。
